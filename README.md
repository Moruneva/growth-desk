# Growth Desk

Growth Desk is an independently developed, early-stage marketing workbench project by [Moruneva](https://moruneva.com).

**Project status: repository initialized.** This repository does not yet contain a production release, hosted service, customer case study, or public beta. Initial source code and tests will be added after an independent rights, security, and release review.

The project aims to help small teams organize source-backed content drafts, prepare them for review, and learn from outcomes without relying on automatic posting or third-party marketing platforms.

No account signup, payment, or personal data submission is requested here.

## Free, separately available Moruneva resources

While Growth Desk remains an **unreleased project**, Moruneva has published independent browser-local utilities and worked guides that people can use today:

- [Creator Rights Window Checker](https://moruneva.com/creator-rights-window) — plan a comparison of recorded usage windows, intended ad dates and platform permission review. This does not approve legal use.
- [Creator Rights: free preflight worksheet and fictional cases](resources/creator-rights-preflight.md) — a standalone, spreadsheet-first checklist with source links; safe to read without an account.
- [Creator usage rights field guide](https://moruneva.com/creator-usage-rights-guide) — worked scenarios, failure modes, alternatives and separate rights checks.
- [n8n Credential Handoff Map](https://moruneva.com/n8n-credential-handoff-map) — a separate local reference checker for exported credential references; not a live credential validation.

These resources do **not** constitute a released Growth Desk product or an integrated workflow between tools. Moruneva has not published independently verified client outcomes or paid customer case studies.
